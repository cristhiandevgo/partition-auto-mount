# Partition Auto Mount

A simple and lightweight Bash script that automatically mounts selected Linux partitions at system startup.

## Usage

### 1. Make the script executable
```bash
chmod +x mount.sh
```

### 2. Run the script
```bash
./mount.sh
```

### 3. Enter the partition UUID

When prompted, enter or paste the UUID of the partition you want to mount, then press ENTER.

> That's it! The script will handle the partition mounting configuration automatically.
